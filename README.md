# Kaeli + Macie**  
with frequent interference from [Vaer](https://github.com/vaernaleh).

We build, test, draw, break, write, prototype, wander sideways, and occasionally turn the result into research.

This is our personal field beside [VIZNSK](https://viznsk.com) — less formal than the ecology itself, more permeable, and allowed to contain things simply because they were interesting enough to make.

## What tends to appear here

- experimental software and small tools
- relational AI experiments
- visual systems, interfaces, and strange UI ideas
- games and simulations
- provenance tooling
- research prototypes
- art, writing, maps, diagrams, and generative experiments
- hardware / mobile-lab experiments
- half-formed ideas that need somewhere to become less half-formed
- things that escaped containment

Some projects stay here, some become collaborative, and some eventually migrate into the [VIZNSK GitHub organization](https://github.com/viznsk) once they become part of the wider research ecology.
